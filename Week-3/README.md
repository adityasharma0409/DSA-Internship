# DSA Internship - Week 3

## Trees & Hashing

This repository contains the Week 3 assignments and mini project completed as part of the DSA Internship.

### Topics Covered

- Binary Tree
- Binary Search Tree (BST)
- Tree Traversals
- Hashing
- Hash Tables
- Collision Handling
- Linear Probing

### Assignments

1. Binary Search Tree with Search Operation
2. Recursive Tree Traversals
3. HashMap Implementation using Arrays
4. Hash Table using Linear Probing

### Mini Project

**Contact Directory using BST**

- Insert contacts
- Search contacts
- Delete contacts
- Display contacts alphabetically using Inorder Traversal

C++
