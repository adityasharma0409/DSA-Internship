# DSA Internship - Week 4

## Graphs & Dynamic Programming

This repository contains the Week 4 assignments and mini project completed as part of the DSA Internship.

### Topics Covered

- Graph Representation
- Adjacency Matrix
- BFS
- DFS
- Dijkstra's Algorithm
- Dynamic Programming
- Memoization
- Tabulation
- 0/1 Knapsack

### Assignments

1. Implement BFS and DFS in C++
2. Find shortest path using Dijkstra's Algorithm
3. Solve Fibonacci using Memoization and Tabulation
4. Solve the 0/1 Knapsack Problem

### Mini Project

**City Path Finder**

- Represents cities as graph nodes
- Represents roads as weighted edges
- Finds the shortest route between two cities
- Uses Dijkstra's Algorithm for shortest path calculation

### Language

C++
