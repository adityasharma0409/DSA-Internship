# DSA Internship - Week 2

## Linked List, Stack & Queue

This repository contains the Week 2 assignments and mini project completed as part of the DSA Internship.

### Topics Covered

- Singly Linked List
- Doubly Linked List
- Stack
- Queue
- Dynamic Memory Allocation
- Undo and Redo Operations

### Assignments

1. Singly Linked List with Insert and Delete
2. Stack Implementation using Linked List
3. Queue Implementation using Array
4. Reverse a Linked List using Stack

### Mini Project

**Undo-Redo Text Editor Simulation**

- Uses stacks to store actions
- Implements Undo operation
- Implements Redo operation
- Demonstrates stack-based action management

### Language

C++
