# DSA Internship - Week 1

## DSA Fundamentals & Arrays

This repository contains the Week 1 assignments and mini project completed as part of the DSA Internship.

### Topics Covered

- Introduction to DSA
- Time and Space Complexity
- Arrays and Strings
- Linear Search
- Binary Search
- Bubble Sort
- Array Reversal

### Assignments

1. Linear Search
2. Binary Search on a sorted array
3. Bubble Sort with swap count
4. Reverse an array without using an extra array

### Mini Project

- Takes marks of N students as input
- Sorts the marks
- Displays the top 3 marks
- Calculates the average score
